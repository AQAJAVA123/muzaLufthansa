# Lufthansa Automation Project

Автоматизация функциональных тестов сайта [United](https://www.united.com/en/us) с использованием Java, Selenium и TestNG.

---

## 📌 Что тестируется

Функциональность формы поиска рейсов:
- Поиск с валидными и невалидными данными
- Проверка правил валидации (даты, пустые поля)
- Переходы между экранами поиска, результатов и бронирования

## 🚀 Как запускать

### Установки
- Java 11+
- Maven
- Браузер Chrome

### Команда запуска
```bash
mvn clean test
```

### Файл конфигурации
- `pom.xml` содержит все зависимости: Selenium, TestNG, WebDriverManager
- WebDriver запускается автоматически в `BaseTest`

---

## 🧪 Используемые техники тест-дизайна

- **Классы эквивалентности** — валидация email, даты, обязательных полей
- **Pairwise** — комбинации параметров (реализуются в полной версии)
- **Диаграмма состояний** — переходы между экранами: поиск → результаты → бронирование
